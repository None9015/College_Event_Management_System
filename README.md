A modern web application for registration of events, their descriptions, timings and venue happening in college digitally and quickly.

Features: 

**QR Code Pass**: A QR pass is generated after every event registration for the organizers to scan it and give them entry in a feasible, quick and systematic way with less confusions and work.
**24 hour remainder**: A notification comes up 24 hours before any event happening before hand.
**Team Matchmaking**: For hackathons, student can enter their team name, search for people who share the same mind with relevant skills to build a formidable team
**Secure logins**: Organizer and student logins are differentiated 
**Organizer Control**: Organizer has the authority to add, edit events 
**Dark theme interface**: Interactive dark themed interface which lets students access any event, read its description and timings and venue and register for them.

**Frontend:** React, Vite, Tailwind CSS, Lucide React
**Backend & Auth:** Supabase

**Website:** https://college-event-manage-7s3m.bolt.host
